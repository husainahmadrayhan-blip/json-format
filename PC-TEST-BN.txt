Windows PC পরীক্ষা:
1. ZIP-এর সব ফাইল একই ফোল্ডারে Extract করুন। ZIP খুলে ফাইল আলাদা করে চালাবেন না।
2. RUN-LOCAL-WINDOWS.bat ডাবল ক্লিক করুন। Python 3 লাগবে; npm থাকলে নতুন React build হবে, না থাকলে ZIP-এ দেওয়া প্রস্তুত dist চলবে।
3. সার্ভার নিজে ব্রাউজারে সঠিক নতুন URL খুলবে। না খুললে কালো উইন্ডোর 'খুলুন http://127.0.0.1:.../index.html?v=58' URL কপি করুন।
4. বাম ঘরে ফরম্যাট পেস্ট করুন; 'নিয়ম দিয়ে JSON' চাপুন। ডান ঘরের প্রতিটি তথ্যের নিচে মূল ফরম্যাটের মিলে যাওয়া লাইন দেখুন।
5. কাজ শেষ হলে কালো উইন্ডোতে Ctrl+C চাপুন। এই লোকাল পরীক্ষা Render/GitHub আপডেট করে না।
