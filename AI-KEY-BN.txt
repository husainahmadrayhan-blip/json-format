Groq/Gemini key লিখে Key সেভ চাপলে শুধু এই ব্রাউজারের localStorage-এ থাকবে। Key পরীক্ষা চাপলে provider API ও মডেল পাওয়া যায় কি না দেখা যায়। AI Parse বোতাম শুধু নিয়মে খালি থাকা অনুমোদিত ফিল্ডের জন্য API কল করে; নিয়মে সব তথ্য থাকলে কোনো API কল করে না এবং বার্তা দেখায়। Gemini JSON request ঠিক করা হয়েছে এবং gemini-3.5-flash-lite মডেল ব্যবহার করে। PC-তে ZIP Extract করে RUN-LOCAL-WINDOWS.bat চালান। Shared PC-তে key সেভ করবেন না।
